Execution profile

WEB-03

Local Qwen/Ollama and Pi remain on their existing internal-only Docker network. In Web Access mode, only this application's host-side permission broker can fetch a user-approved public page. No model prompt, browser cookies, or local files are automatically sent.

Offline is the default. Web Access does not grant downloads, installs, or unrestricted browsing.

Propose public webpage

Provider selection is saved locally. Each proposed search retains the provider chosen when requested; switching providers never redirects an already approved search.

Webpage fetches reveal your public IP and requested URL to the destination, including path/query. Search phrases could contain private details; Search phrases are sent to the provider bound to each search request only after approval. Custom SearXNG servers may log submitted queries. The model may propose either operation through the broker.

Future read-only access

These grants are separate from selecting existing requests. They apply to future page/search proposals and never authorize downloads, installs, uploads or script execution. All expire at restart.

A global/broad grant requires a second explicit confirmation. Auto-grants approve requests; searches and pages execute only through a separate broker retrieval operation.
